# 99A 新增炮弹 DTC201-125

为 War Thunder Offline 的 ZTZ99A 新增 DTC201-125。两种穿深均为虚构的游戏设定，以 10 米垂直命中为基准。

## 安装

1. 退出游戏，把上面任选一个 ZIP 原样放入离线版的 `Mod` 文件夹。切换版本前先移出旧的 DTC201-125 ZIP 或 `ztz99a_dtc201` 文件夹。
2. 启动离线版，在 ZTZ99A 的主炮弹药列表选择 DTC201-125。

适用于本项目的 War Thunder Offline 2.59.0.92 兼容构建。加载器需要支持 `char` 资源和 `ztz99aDtc201`。旧版主菜单人数或穿越者覆盖包会替换加载器，与炮弹模组合用时需保留这两项支持。
